# SUPPLY_CHAIN_ANALYTICS
Supply Chain Analytics Dashboard | Power BI

This project is an interactive Supply Chain Analytics Dashboard built using Microsoft Power BI to analyze key operational and order-related metrics and turn raw data into meaningful business insights.

🎯 Project Objective

The dashboard provides a consolidated view of supply chain performance, helping analyze production volume, order quantity, stock availability, lead time, transportation modes, customer types, cities, and product revenue.

📊 Key KPIs
Average Production Volume: 567.84
Total Quantity Ordered: 4,922
Average Lead Time: 17.1 Days
Total Stock Available: 4,777
📈 Dashboard Analysis

The dashboard includes visualizations for:

Total Orders by City
Revenue Generated by Product
Orders by Customer Type
Transportation Mode Distribution
Production & Inventory performance
Lead Time analysis
🛠️ Tools & Techniques
Microsoft Power BI
Power Query for data cleaning and transformation
Data Modeling
DAX
KPI Development
Interactive Charts, Slicers & Visualizations
Business Data Analysis
💡 Key Insights
The dashboard makes it easier to identify differences in order volumes across cities, product-level revenue performance, transportation preferences, customer distribution, inventory availability, and lead-time performance.
